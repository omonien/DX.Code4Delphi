# Changelog

## 1.0.0 (2025)

* High-quality TextMate grammar for Delphi / Object Pascal covering Delphi 13.1 language features and all older versions.
* Delphi-IDE style navigation: `Ctrl+Shift+Up/Down` and `Ctrl+Alt+Up/Down` (interface ↔ implementation), `Alt+Up/Down` (next/previous method), with overload-aware matching.
* Folding provider for sections and `begin…end` blocks; `{$REGION}` support.
* Language configuration: comment toggling, auto-closing pairs, word patterns.
* Fully configurable via `delphi.*` settings; all keybindings can be re-bound or disabled.
* 49 automated tests covering the parser, navigation engine, grammar tokenization and activation.
